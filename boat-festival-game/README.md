# 龙舟盛景 · 端午竞渡（Dragon Boat Festival 3D）

在 `vr-paint-multi` 端午主题之上，用纯 Three.js 重构的一个**自包含、双击即玩**的 3D 端午龙舟场景与小游戏。无需后端、无需构建、无外部资源依赖（仅 CDN 加载 Three.js 与 OrbitControls）。

## 玩法

三种模式（左侧切换）：

- **自由观赏**：镜头自动绕场巡游，五舟并排竞渡，岸边人群欢呼。
- **龙舟竞速**：操控中央龙舟，敲鼓（空格 / 点鼓按钮 / 连点）积累桨力冲刺，与 4 艘 AI 竞渡，低角度跟拍 + 实时名次 / 桨力 / 赛程 HUD，撞线判时报名次。
- **空间绘画**（继承自 a-painter / vr-paint 的灵魂）：在 3D 空间挥毫，6 种笔触——圆管 / 绸带 / 毛笔 / 星光 / 下雨 / 下雪，粗细 1~40，多色调色板，撤销 / 清空。

右侧动作：时辰切换（白昼 / 黄昏 / 夜晚，改变天空、光照、水色）、放烟花、放河灯。

## 运行

- 双击 `start.bat`（自动起本地静态服务器并打开浏览器，端口 8331），或
- 直接用浏览器打开 `index.html`（需联网加载 CDN）。

`stop.bat` 用于停止服务器。

## 技术说明

- 纯 `Three.js`（r128，CDN）+ `OrbitControls`，无后处理插件，效果全靠几何建模、材质与配色。
- 多人联机接口在原 `vr-paint-multi` 已具备（Go WebSocket），本场景默认单机，可后续接入。
